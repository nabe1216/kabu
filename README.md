# DIVIDEND HEIST

東証プライム × 高配当銘柄の自動シグナル生成ツール。

J-Quants API から日次でデータを取得し、スクリーニング・バケット分類・シグナル判定・ボックス相場判定を行い、ダッシュボード（`index.html`）で表示する。

GitHub Pages + GitHub Actions で完全自動運用。月3,300円（J-Quants Standard）のみで稼働。

## 仕様サマリ（2026年11月6日更新。20年分の検証の結論を反映）

### ユニバース
- 東証プライムのうち TOPIX Core30・Large70・Mid400・Small 1（約970社）

### スクリーニング（8条件すべて通過 = PASS）
1. 減配ゼロ（過去10期）※累進・DOE銘柄は免除。株式分割・併合は減配と数えない
2. 売上の安定性（過去5期で-10%超下落が2期連続なし）
3. 営業利益の安定性（同上）
4. 純利益の安定性（同上）
5. 配当性向 ≤ 50%
6. 自己資本比率 ≥ 50%（建設・海運・卸売は33%、金融・不動産は免除）
7. PER × PBR ≤ 40
8. 最低利回り ≥ 3.0%（累進・DOE銘柄は免除）

### 買い方（検証運用 `portfolio_engine.py`）
- 8条件を通り、PBR が全銘柄の安い側20%に入る銘柄を、Tier 順（S→A→B）・PBR の低い順に買う
- 1銘柄の予算：総資産 ÷ 15 × Tier の重み（S 2.0 ／ A 1.5 ／ B 1.0）÷ 1.5。100株単位・最大20銘柄
- 配当で買い増し：月に1回、残った現金で、目標の大きさをいちばん下回っている持ち株を100株ずつ目標まで
- 12月の損出し：12月15日以降の最初の実行日に、取得単価より2%以上下がっている持ち株を売って同じ株数を買い戻す
- 税：売却益と配当に20.315%。売却の損は配当と相殺（特定口座）

### 売り方
- 減配（年間配当の実績が前の期より10%超減少。分割・併合は除く）、累進配当撤回、営業利益 YoY -20% 以下のときだけ
- それ以外は売らない（利確・損切り・入れ替え・相場や市況で切り替える売買は、20年分の検証でどれも成績を上げなかった）

### 配当の分割・併合の扱い（2026年11月6日に直した）
- 実績の年間配当は、期末の7日前より後の分割・併合で、いまの株数の基準に直す（期末が基準日の分割を減配と読まない）
- 期の途中で分割・併合した期は、減配の比べに使わない
- 分割・併合を読むため、株価は10年前から取る（取れなければ9年分。そのときは分割・併合が読めない古い期を減配の比べから外す）
- 同じ期の決算短信が2つ以上あるときは、あとの開示だけを使う（同じ期を2回数えない）
- 予想配当は、開示から270日以内に1.25倍以上の分割・併合があれば、直前の予想に近い読み方を採る

### 参考表示
- BOX（横ばい相場。ADX(14) < 22・値幅 8〜20%）：検証では、ボックスの上下で売り買いしても成績は上がらなかった
- 割安（PER・PBR が過去の中央値より低い）

### 検証でわかったこと（2009〜2026年）
- 17年で年13.9%（TOPIX 9.8%）。ただし差は偶然と区別できず、TOPIX に勝つ手法とは言えない
- 配当は減りにくい。8条件は減配する銘柄を半分にする（成績ではなく配当の保険）
- 下げ相場でも買い続ける。市況（日経平均・金利・原油・為替・VIX）で切り替える形は効かなかった

## セットアップ

詳細は同梱の **セットアップ手順書 (PDF)** を参照。要点のみ：

1. [J-Quants Standard](https://jpx-jquants.com/) を契約（3,300円/月）し、リフレッシュトークンを発行
2. このリポジトリを Public で作成
3. ファイルを配置してコミット&プッシュ
4. **Settings → Secrets and variables → Actions** で `J_QUANTS_API_KEY` にリフレッシュトークンを登録
5. **Settings → Pages** で `main` ブランチをソースに設定
6. **Actions** タブから `Generate Dividend Signals` を手動実行（初回）
7. `https://<username>.github.io/dividend-heist/` にアクセスして表示確認

## ローカル開発

```bash
# 依存インストール
pip install -r scripts/requirements.txt

# .env を作成（リポジトリにはコミットしない）
echo 'J_QUANTS_API_KEY=your_refresh_token_here' > .env

# 実行
export $(cat .env | xargs)
python scripts/generate.py

# 出力確認
ls -lh data/results.json
```

## 設定変更

`scripts/generate.py` の冒頭にある定数を編集すれば、即時反映可能：

```python
MIN_YIELD_THRESHOLD = 3.0       # 最低利回り
GRAHAM_THRESHOLD = 40.0         # PER × PBR の上限
PAYOUT_RATIO_MAX = 50.0         # 配当性向上限
EQUITY_RATIO_MIN = 0.50         # 自己資本比率下限
BOX_ADX_THRESHOLD = 22.0        # ボックス判定の ADX 上限
```

累進配当・DOE 銘柄リストは `PROGRESSIVE_DECLARED` / `DOE_LIST` セットを編集。
